Completely free, lightweight menu bar D-day counter for macOS

Pros(and cons)
- Completely free with no in-app purchases (i doubt any cons for this)
- Made for macOS 27 Golden Gate (I do not know if it works on older versions)
- Apple Silicon native (Intel support untested)
- Very lightweight (no features)
- Liquid Glass (ew)

Because it contains Liquid Glass components, build fails on versions macOS 15 or lower.

Made with love for tracking how many days left until IB final exams

This does not work with Hidden Bar extension. I've tried it. Ended up giving Hidden Bar up btw.
